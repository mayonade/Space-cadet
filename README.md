# Nebula Drift Pinball

An original space-themed pinball table for phones and desktops. One HTML file, no dependencies.

- Open `index.html` in any browser to play.
- Tap the left or right side of the screen to flip. Hold the right side to pull the launcher, then release.
- Keyboard: arrow keys flip, Space launches.

Edit `src/game.html`, then run `./build.sh` to regenerate `index.html`.
